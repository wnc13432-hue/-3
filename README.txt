رحلة التحضيري - تطبيق ويب تقدّمي (PWA)

الملفات: index.html, manifest.webmanifest, sw.js, والأيقونات.

طريقة النشر (مجانًا):
1) ارفع محتويات المجلد كما هي إلى استضافة تدعم HTTPS، مثل Netlify (Drop) أو GitHub Pages أو Cloudflare Pages.
2) افتح الرابط على الهاتف.
3) أندرويد (Chrome): القائمة ثم «تثبيت التطبيق».
   آيفون (Safari): زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».
4) بعد أول فتح يعمل التطبيق دون إنترنت.

لتحويله إلى ملف APK لمتجر Google Play: ارفع رابط الموقع إلى pwabuilder.com.
ملاحظة: لا يعمل التثبيت عند فتح index.html مباشرة من الجهاز، بل يلزم رابط HTTPS.
